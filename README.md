# CBT System - Computer Based Test Platform

## Features
- Three user roles: Admin, Teacher, Student
- Class and Subject management
- Question bank with Excel import support
- Image-based questions
- Timed CBT exams
- Real-time question palette with visual indicators
- Auto-save answers
- Automated scoring and result generation
- Report card generation
- Student admission to next class

## Requirements
- PHP 8.1 or higher
- Composer
- MySQL/MariaDB
- Node.js & NPM (for asset compilation)
